# NWNHotkeys-V2

Welcome to NWNHotkeys-V2, in this project I will be trying to recreate my AutoHotkey tool for Neverwinter Nights, that helps to simplify buying multiples of items from shops in game at a quicker pace than would be achievable manually.

for the original project and possibly more information as to the tools function please refer to the original repository at https://github.com/DrowArrow/NWNHotkeys

Main differences for the python version are as follows:

1. when making changes to the buycount or the hotkey there is no update button instead you press your enter/return key and a message will pop up at the bottom of the window telling you it's been updated.
2. there are no transparency or always on top settings for this version i never got around to it and no guarantee i ever will. maybe if anyone shows an interest in such things i'll come back to it.

# Current Progress

Main goals have been met and script is fully functional at it's core, next steps are to add Quality of Life features like Opacity and always on top features for the GUI.
